《相鼠》

作者先秦詩歌，作者不詳
出處《詩經．鄘風》
體裁四言詩
題解「相」有察看、看之意；全詩借老鼠反襯人，諷刺無禮之人。

📖 內容

  • 第一層：老鼠有皮，人卻「無儀」。
  • 第二層：老鼠有齒，人卻「無止」。
  • 第三層：老鼠有體，人卻「無禮」。

🎯 主旨

借老鼠有皮、有齒、有體，反襯人卻沒有儀容、容止和禮義，諷刺不重禮儀、道德的人。

⭐ 必記

有皮 → 無儀　｜　有齒 → 無止　｜　有體 → 無禮
「相鼠有皮，人而無儀。」
「相鼠有齒，人而無止。」
「相鼠有體，人而無禮。」

《無衣》

作者先秦詩歌，作者不詳
出處《詩經．秦風》
體裁四言詩
題解以共同分享衣物、準備兵器、一起出征，表現同甘共苦、共同抗敵的精神。

📖 三章結構

章衣武器行動
一同袍戈矛與子同仇
二同澤矛戟與子偕作
三同裳甲兵與子偕行

🎯 主旨

表現人民同甘共苦、團結一致、共同抗敵的精神。

⭐ 必記

同袍 → 同澤 → 同裳；戈矛 → 矛戟 → 甲兵；同仇 → 偕作 → 偕行
「豈曰無衣？與子同袍。」
「與子偕行。」

《蓼莪》

作者先秦詩歌，作者不詳
出處《詩經．小雅》
體裁抒情詩
題解追念父母養育之恩，悲痛自己不能報答、終養父母。

📖 內容線索

  1. 回想父母生我、養我、育我的辛勞。
  2. 父母離世後，產生「無父何怙？無母何恃？」的悲痛。
  3. 回憶父母恩德深厚，感到難以報答。
  4. 最後流露不能終養父母的遺憾。

🎯 主旨

感念父母養育之恩，抒發失去父母後的悲痛，以及不能及時報答、終養父母的遺憾。

⭐ 必記

「哀哀父母，生我劬勞。」
「無父何怙？無母何恃？」
「欲報之德，昊天罔極。」

《季氏章》

常見篇名《季氏將伐顓臾》
出處《論語．季氏》
人物孔子、冉有、季路、季氏
文體語錄體／議論

📖 文章內容

  1. 季氏準備攻打顓臾，冉有、季路向孔子說明。
  2. 孔子指出顓臾沒有被攻打的正當理由。
  3. 孔子責備冉有、季路沒有盡臣子的責任。
  4. 用「虎兕出於柙，龜玉毀於櫝中」說明看守者應負責。
  5. 提出「不患寡而患不均，不患貧而患不安」的政治原則。
  6. 主張「修文德以來之」，以德服人，而不是只靠武力。
  7. 以「吾恐季孫之憂，不在顓臾，而在蕭牆之內也」指出真正危機可能來自內部。

🎯 主旨

反對不義攻伐，主張政治應重視公平、和諧、安定及德治；同時強調臣子應負起自己的政治責任。

⭐ 必記

「陳力就列，不能者止。」
「不患寡而患不均，不患貧而患不安。」
「均無貧，和無寡，安無傾。」
「吾恐季孫之憂，不在顓臾，而在蕭牆之內也。」

《舜發於畎畝之中章》

出處《孟子．告子下》
作者孟子
文體議論文
核心生於憂患，死於安樂

📖 論證結構

  1. 先舉例：舜、傅說、膠鬲、管夷吾、孫叔敖、百里奚等人都曾處於困境，後來得到重用。
  2. 再推論：「天將降大任於是人也」必先讓他受磨練。
  3. 再談個人：人會在犯錯、困惑和壓力中改變、奮發。
  4. 再談國家：國內沒有能臣、國外沒有外患，國家反而容易滅亡。
  5. 最後結論：「生於憂患，而死於安樂。」

🎯 主旨

說明困難與憂患能磨練人的意志、增加能力；過度安逸則容易令人失去警覺，甚至導致失敗。

⭐ 必記

「故天將降大任於是人也，必先苦其心志，勞其筋骨，餓其體膚……」
「所以動心忍性，曾益其所不能。」
「人恆過，然後能改。」
「困於心，衡於慮，而後作。」
「生於憂患，而死於安樂。」

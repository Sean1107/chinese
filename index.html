核心知識點回顧
1. 光的反射與折射
  • 反射定律：入射角等於反射角（i = r）。平面鏡成等大對稱虛像；鏡面旋轉角度 θ，反射光線偏轉 2θ。
  • 折射定律 (Snell's Law)：n₁ sin θ₁ = n₂ sin θ₂。光疏入光密向法線偏折（θ₂ < θ₁）。
  • 折射率：n = cv = λ₀λ（真空光速與介質光速之比）。跨介質時頻率 f 恆定不變。
  • 垂直視深：d' = dn（水中物體看起來比實際更淺）。
  • 色散現象：紫光頻率高、折射率大、偏折最大；紅光折射率小、偏折最小。
2. 全反射 (Total Internal Reflection)
  • 發生條件：① 光必須由光密介質射向光疏介質（n₁ > n₂）；② 入射角大於或等於臨界角（θ₁ ≥ C）。
  • 臨界角公式：sin C = n疏n密（若射向空氣，則 sin C = 1n）。
  • 典型臨界角：水（C ≈ 48.8°）、玻璃（C ≈ 41.8°）、鑽石（C ≈ 24.4°，極易全反射故閃耀璀璨）。
  • 工程應用：光纖通信（纖芯折射率大於包層 ncore > ncladding）、等腰直角稜鏡（90°/180°光路轉向）、海市蜃樓。
3. 光的干涉 (Interference)
  • 相干光條件：頻率相同、相位差恆定、振動方向相同。干涉確立了光的波動學說。
  • 光程差公式：Δr = r₂ - r₁ = d sin θ ≈ dxl（其中 x 為屏上點至中央亮紋之距離）。
  • 明暗條紋條件：明紋 Δr = mλ ⇒ xm = mlλd；暗紋 Δr = (m + ½)λ ⇒ xm' = (m + ½)lλd。
  • 條紋間距公式：Δx = lλd（條紋等間距、等寬度）。紅光條紋寬於藍光；若入水波長變短條紋變窄。
  • 白光干涉：中央為白色亮紋，兩側為彩色條紋，且靠近中央側偏紫、外側偏紅（內紫外紅）。
4. 光的衍射與偏振 (Diffraction & Polarization)
  • 顯著衍射條件：障礙物或狹縫尺寸與波長相當或更小（a ≤ λ）。
  • 單縫衍射特徵：中央明紋極寬（約為兩側一級明紋的 2 倍）、極亮；兩側亮度急劇衰減，條紋寬度不均勻。
  • 衍射光柵：d sin θ = mλ。條紋銳利明亮，分光性能優良。
  • 偏振與橫波：縱波（如聲波）絕無偏振現象，偏振唯一證明光是橫波 (Transverse Wave)。
  • 馬呂斯定律：I = I₀ cos²θ。自然光過單偏振片光強減半（I = ½I₀）；正交消光（θ = 90° ⇒ I = 0）。
  • 布儒斯特角：tan θB = n，此時反射光與折射光互相垂直，反射光為完全偏振光。

1.(2分)
光從空氣斜射入水中時，光波的傳播速度變慢，波長變短，但光的頻率保持不變。
✅ 標準答案：正確 (True)
解析：光的頻率由光源決定，跨介質傳播時頻率不變；水折射率大於空氣，光速 v = c/n 減小，波長 λ = λ₀/n 變短。
2.(2分)
只要光線射向介質界面的入射角大於臨界角，就一定會發生全反射現象。
✅ 標準答案：錯誤 (False)
解析：全反射必須滿足兩個條件：① 光必須由光密介質射向光疏介質；② 入射角大於或等於臨界角。光疏入光密不會發生全反射。
3.(2分)
在楊氏雙縫干涉實驗中，若保持其他條件不變，僅增大雙縫間距 d，光屏上相鄰明條紋間距 Δx 將隨之增大。
✅ 標準答案：錯誤 (False)
解析：由雙縫干涉公式 Δx = lλ/d 可知，條紋間距與雙縫間距 d 成反比。增大 d 會使條紋間距 Δx 減小。
4.(2分)
在單縫衍射圖樣中，中央明條紋最寬且最亮，兩側各級明條紋寬度明顯變窄且亮度急劇減弱。
✅ 標準答案：正確 (True)
解析：單縫衍射條紋是不均勻的，中央明紋寬度約為兩側一級明紋的 2 倍，且集中了絕大部分光能，兩側條紋亮度和寬度迅速衰減。
5.(2分)
聲波和光波都是波動，因此在適當條件下，聲波在空氣中傳播時也能觀察到明顯的偏振現象。
✅ 標準答案：錯誤 (False)
解析：偏振是橫波特有的性質。聲波在空氣中是縱波（振動方向與傳播方向平行），絕無偏振現象。偏振唯一證明了光是橫波。
6.(2分)
光纖通信中，纖芯的折射率必須大於外層包層的折射率，光信號才能在兩者界面持續全反射傳輸。
✅ 標準答案：正確 (True)
解析：全反射要求光從光密介質射向光疏介質，故纖芯折射率必須大於包層（n_core > n_cladding）。
二、概念填充題（共 6 小題，每題 2 分，共 12 分） 填充題 12%
7.(2分)
一束光以 60° 入射角射向平面鏡，則反射角為 ______°；若保持入射光方向不變，將平面鏡旋轉 10°，反射光線的方向將偏轉 ______°。
✅ 參考答案：60；20
解析：由反射定律知反射角等於入射角為 60°。鏡面旋轉 10°，法線旋轉 10°，入射角與反射角均改變 10°，故反射光線偏轉 2 × 10° = 20°。
8.(2分)
某透明介質折射率 n = √2 ≈ 1.414，光在該介質中速度約為 ______ m/s；該介質對空氣的臨界角為 ______°。
✅ 參考答案：2.12 × 10⁸；45
解析：v = c/n = (3.00 × 10⁸)/√2 ≈ 2.12 × 10⁸ m/s；臨界角 sin C = 1/n = 1/√2 ⇒ C = 45°。
9.(2分)
波長為 500 nm 的綠光照射雙縫。若接收屏上 P 點到兩縫的光程差為 1500 nm，則 P 點處出現第 ______ 級______條紋（填「明」或「暗」）。
✅ 參考答案：3；明
解析：光程差 Δr = 1500 nm = 3 × 500 nm = 3λ，為波長整數倍（m = 3），對應第 3 級相長干涉明條紋。
10.(2分)
光繞過障礙物偏離直線傳播的現象稱為光的衍射。發生顯著衍射的必備條件是障礙物或狹縫尺寸與光波波長______。
✅ 參考答案：相近或小於波長（或相當）
解析：障礙物尺寸遠大於光波長時光沿直線傳播；只有尺寸與波長相當（a ≤ λ）時，衍射現象才顯著。
11.(2分)
波動分為橫波與縱波。實驗中光的______現象無可置疑地證明了光是一種橫波。
✅ 參考答案：偏振 (Polarization)
解析：干涉和衍射僅證明波動性，而偏振特性唯獨橫波具備，故偏振現象唯一證明光是橫波。
12.(2分)
光強為 I₀ 的自然光穿過理想偏振片後成為線偏振光，光強為 ______；若該線偏振光再穿過透振方向與其夾角為 60° 的檢偏片，出射光強為 ______。
✅ 參考答案：0.5 I₀；0.125 I₀（或 ⅛ I₀）
解析：自然光穿過起偏片光強減半為 0.5 I₀；再過檢偏片依馬呂斯定律 I = (0.5 I₀) cos²60° = 0.5 I₀ × (0.5)² = 0.125 I₀。

13.(3分)
一束單色光從真空中以 45° 入射角射入某介質，折射角為 30°。則該介質折射率及光在介質中的速度為：
A n = √2 ≈ 1.414，v ≈ 2.12 × 10⁸ m/s
B n = 0.707，v ≈ 4.24 × 10⁸ m/s
C n = √3 ≈ 1.732，v ≈ 1.73 × 10⁸ m/s
D n = 1.500，v ≈ 2.00 × 10⁸ m/s
✅ 正確答案：A
解析：由斯涅爾定律 n = sin 45° / sin 30° = (√2/2) / (1/2) = √2 ≈ 1.414；v = c/n = 3.00 × 10⁸ / √2 ≈ 2.12 × 10⁸ m/s。選 A。
14.(3分)
清澈水池的實際深度為 2.4 m，水的折射率為 1.33。人垂直俯視池底時，看起來的視深約為：
A 3.19 m
B 2.40 m
C 1.80 m
D 1.20 m
✅ 正確答案：C
解析：由垂直視深公式 d' = d / n = 2.4 / 1.33 ≈ 1.80 m。水底看起來比實際更淺。選 C。

光從介質 1 射向介質 2，若想在界面發生全反射，必須滿足的條件是：

16.(3分)
在楊氏雙縫干涉實驗中，欲使光屏上相鄰明條紋間距 Δx 增大，下列措施有效的是：
A 減小雙縫到光屏的距離 l
B 增大雙縫間的間距 d
C 將入射光由藍光改為紅光
D 將整個實驗裝置浸入水中進行
✅ 正確答案：C

17.(3分)
若用白光照射雙縫，則光屏上呈現的干涉條紋特徵為：
A 中央為暗條紋，兩側為黑白條紋
B 中央為純白色明條紋，兩側彩色條紋內側偏紫、外側偏紅

B 雙縫干涉中央明紋寬度是兩側明紋寬度的兩倍

21.(8分)【實驗：用插針法測定玻璃磚的折射率】
某實驗小組在「測定長方形平行玻璃磚折射率」實驗中，利用四枚大頭針 P₁、P₂、P₃、P₄ 進行光路追蹤：
(1) 在插針確定光路時，透過玻璃磚觀察，插上 P₃ 時應擋住 ______ 的像；插上 P₄ 時應同時擋住 ______ 的像。（2分）
(2) 某同學在紙上畫出兩表面邊界 aa' 和 bb'，但在放置玻璃磚時不慎將玻璃磚向下平移了一小段距離（即玻璃磚實際邊界在 aa' 下方），若其餘操作規範，則測得的折射率值將 ______（填「偏大」、「偏小」或「不變」），試說明原因。（3分）
(3) 為了提高測量精確度，請寫出兩項關鍵的操作注意事項。（3分）
參考答案與評分標準：
(1) P₁、P₂ 的像；P₃ 以及 P₁、P₂ 的像。(2分)
(2) 偏小。(1分) 原因：玻璃磚向下平移導致測得的折射角 r 比真實折射角偏大，由 n = sin isin r 知，分母偏大使得測得的折射率 n 偏小。(2分)
(3) 操作要領：① 大頭針 P₁與P₂、P₃與P₄ 之間的間距應適當大一些（宜大於 4~5 cm），以減小確定光線方向時的視角誤差；② 入射角應適中（宜在 30°~60° 之間），過小折射角測量相對誤差大，過大反射光太強出射光暗弱；③ 實驗過程中嚴禁移動玻璃磚。(寫出任意兩點得 3分)
22.(8分)【實驗：用雙縫干涉測量單色光的波長】
在「用雙縫干涉測光的波長」實驗中：
(1) 光具座上各光學元件在遮光筒前沿光軸放置的正確順序為：光源 → ______ → ______ → 雙縫 → 遮光筒 → 測量頭。（填「單縫」或「濾光片」）（2分）
(2) 已知雙縫間距 d = 0.20 mm，雙縫到測量頭分劃板的距離 l = 800 mm = 0.800 m。旋動測量頭手輪，分劃板中心刻線對齊第 1 條亮條紋時讀數為 x₁ = 1.200 mm，對齊第 6 條亮條紋時讀數為 x₆ = 14.000 mm。
    ① 求相鄰亮條紋間距 Δx；（2分）
    ② 計算該單色光的波長 λ（以 nm 為單位）；（2分）
(3) 若實驗中觀察到干涉條紋過於密集、條紋難以分辨，請提出兩種增大條紋間距的具體調節方法。（2分）
參考答案與評分標準：
(1) 濾光片 → 單縫 (2分，順序顛倒不給分)
(2) ① 條紋間距：Δx = x₆ - x₁6 - 1 = 14.000 - 1.2005 = 12.8005 = 2.560 mm (2分)
    ② 波長計算：由 Δx = ldλ ⇒ λ = Δx · dl
    λ = 2.560 × 10⁻³ m × 0.20 × 10⁻³ m0.800 m = 6.40 × 10⁻⁷ m = 640 nm (2分)
(3) 增大條紋間距方法：由 Δx = lλd 可知，可：① 換用間距 d 更小的雙縫片；② 增大雙縫到光屏的距離 l（使用更長的遮光筒）；③ 換用波長更長的濾光片（如改用紅光濾光片）。(答出任意兩點得 2分)

23.(8分)【光導纖維通信與全反射技術應用】
光導纖維（光纖）是現代高速寬帶互聯網與跨大洋海底通信的物理基石：
(1) 光纖由內部的「纖芯」與外層的「包層」構成。纖芯折射率 n₁ 與包層折射率 n₂ 必須滿足什麼關係？請從全反射條件說明其原理。（3分）
(2) 某光纖纖芯折射率 n₁ = 1.60，包層折射率 n₂ = 1.28。
    ① 求光信號在纖芯與包層界面的全反射臨界角 C；（3分）
    ② 簡述光纖相比傳統金屬銅線電纜在信息傳輸方面的兩項突出優勢。（2分）
參考答案與評分標準：
(1) 必須滿足 n₁ > n₂（纖芯折射率大於包層折射率）。(1分)
原理：全反射要求光由光密介質射向光疏介質。只有纖芯折射率高於包層，光在纖芯內部以大於臨界角的角度傳播時，才能在界面持續全反射前進而不漏入包層。(2分)
(2) ① 臨界角計算：sin C = n₂n₁ = 1.281.60 = 0.80 ⇒ C = arcsin(0.80) ≈ 53.1°。(3分)
    ② 突出優勢：① 傳輸頻帶極寬、容量巨大；② 信號衰減極小、傳輸距離遠；③ 抗電磁干擾能力強、保密性好；④ 重量輕、耐腐蝕。(答出任意兩點得 2分)
24.(8分)【偏光太陽鏡與 3D 立體眼鏡的偏振光學原理】
光的偏振特性在生活防護與現代消費電子中有著廣泛應用：
(1) 夏季在柏油路面駕駛或在水面垂釣時，常會受到刺眼的反射眩光困擾。水面或路面的反射光中，主要包含哪個振動方向的偏振光？優質「偏光太陽眼鏡」的鏡片透振方向應設計為水平還是豎直？為什麼？（4分）
(2) 在電影院觀看 3D 立體電影時觀眾需佩戴偏振眼鏡。左右兩眼鏡片的透振方向有何關係？請簡述其成像原理。（4分）
參考答案與評分標準：
(1) 反射眩光特性：水平界面（水面、路面）反射的光主要是水平方向振動的偏振光。(2分)
偏光鏡設計：鏡片透振方向應設計為豎直方向。(1分) 原因：豎直透振方向與水平振動的反射眩光正交垂直（夾角 90°），依馬呂斯定律反射眩光被鏡片完全吸收，而正常景物光線仍可透過，從而消除眩光。(1分)

(2) 3D 眼鏡透振方向：左右兩眼鏡片的透振方向相互正交垂直（夾角 90°）。(2分)
原理：銀幕上同時放映兩部透振方向互垂的偏振光畫面（分別代表左眼與右眼視角）。戴上眼鏡後，左眼只接收左眼畫面，右眼只接收右眼畫面，兩眼獲得存在視差的獨立圖像，大腦融合後重現逼真的三維立體感。(2分)
